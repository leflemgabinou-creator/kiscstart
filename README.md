# Kickstart (VST3) - clone perso

Volume shaper sidechain : SYNC (tempo hote), MIDI (notes), AUDIO (declenche par le son de l'entree ou du sidechain).
16 formes de courbe, longueur reglable (poignee a droite de la courbe), MIX, mode BAND (ne traite que les graves, curseur = frequence, casque = ecoute de la bande).

Build : onglet Actions de GitHub -> artefact `Kickstart-VST3`, a copier dans `C:\Program Files\Common Files\VST3\`.
